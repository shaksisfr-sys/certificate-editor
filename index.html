Подключение к Supabase

Введите ваши URL и Anon Key из консоли Supabase (Project Settings ➔ API). Они сохранятся в браузере.

💡 Как создать таблицу в Supabase SQL Editor: create table certificates (
  id bigint primary key generated always as identity,
  title text not null,
  data jsonb not null,
  created_at timestamp with time zone default now()
);
